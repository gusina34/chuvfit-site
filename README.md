# Сайт chuv.fit

Сайт фитнес-тренера Нины: главная, калькулятор КБЖУ с меню на день и анкета перед стартом.
Анкеты и меню клиенток попадают в Google Таблицу.

| Страница | Файл |
| --- | --- |
| Главная | `index.html` |
| Калькулятор КБЖУ и меню | `kbju.html` (логика — `assets/kbju.js`) |
| Анкета | `anketa.html` (вопросы — `assets/anketa.js`) |
| Продукты и блюда для меню | `assets/food.js` |
| Telegram, Instagram, цена марафона | `assets/config.js` |
| Приём анкет в таблицу | `apps-script/Code.gs` |

Править любой файл можно прямо на GitHub: открыть файл → значок карандаша → **Commit changes**.
Сайт обновится через 1–2 минуты.

## 1. Включить сайт (бесплатно)

Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
Через пару минут сайт откроется по адресу https://gusina34.github.io/chuvfit-site/

## 2. Анкеты и меню в Google Таблицу

Инструкция — в начале файла [`apps-script/Code.gs`](apps-script/Code.gs). Коротко: новая таблица →
Расширения → Apps Script → вставить код → Развернуть как веб-приложение (доступ: все) →
ссылку `/exec` вставить в `scriptUrl` в `assets/config.js`.

Пока ссылки нет, сайт всё равно работает: анкета и меню предлагают скопировать текст и отправить его в Telegram.

По желанию — уведомления в Telegram о каждой новой анкете (свойства скрипта `BOT_TOKEN` и `CHAT_ID`).

## 3. Свой домен

1. Купите домен (например, в reg.ru или nic.ru).
2. В настройках DNS домена добавьте записи:
   - 4 записи типа **A** для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - запись **CNAME** для `www`: `gusina34.github.io`
3. GitHub → Settings → Pages → Custom domain → впишите домен → Save. Когда проверка пройдёт, включите **Enforce HTTPS**.

Хостинг покупать не нужно: GitHub Pages бесплатный.
